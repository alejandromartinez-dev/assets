Sum Gadgets for Jira

Documentation · Sum by field gadget

What it does

Jira's built-in dashboard gadgets count issues. Sum by field adds them up instead. Give it a JQL filter and a numeric field, and it shows the total, a breakdown by status, priority, assignee or issue type, and a bar chart.

Installing

  1. In Jira, go to Apps → Explore more apps.
  2. Search for Sum Gadgets for Jira and install it.
  3. You need Jira administrator permissions to install apps.

Adding the gadget

  1. Open a Jira dashboard, or create one from Dashboards → Create dashboard.
  2. Click Add gadget.
  3. Search for Sum by field and add it.
  4. The configuration screen opens automatically.

Configuring it

FieldWhat to enter
JQL filter Any valid JQL query, for example project = ABC or project = ABC AND sprint in openSprints(). This decides which issues are included.
Field to sum The dropdown lists every numeric field that exists in your site — story points, estimates, and any custom number field you have created.
Group by Status, Priority, Assignee or Issue type. This is how the breakdown below the total is split.

Click Save. You can change any of it later from the gadget's ⋯ → Edit menu.

Reading the result

  • The large number is the total of the chosen field across all matching issues.
  • Under it: the field name, how many issues matched, and how many of them have no value in that field.
  • Each row shows a group, its sum, its share of the total, and its issue count.
  • The chart shows the same groups visually.

Story Points or Story point estimate?

Jira has two similar fields and only one of them usually holds your data. Story Points is used in company-managed projects; Story point estimate is used in team-managed ones. Which one is filled in depends on how your project was created.

The gadget lists both if both exist. If you pick the wrong one it will not show a misleading zero — it tells you that the field has no values for those issues, so you can switch to the other one.

Troubleshooting

The total is 0 and it says "no values found"

The field you chose is empty for those issues. Try the other story point field, or check that the field is present on the issue screens for that project.

"Your JQL isn't valid"

The message includes Jira's own explanation. The most common causes are a project key that doesn't exist and a missing AND or OR. You can test the query in Filters → Advanced issue search first.

Some issues are missing from the total

The gadget runs every query with the permissions of the person looking at it. If a viewer cannot see a project in Jira, its issues are not counted for them. Two people looking at the same gadget can legitimately see different totals.

Only part of my results are counted

The gadget reads up to 5,000 issues per query. Above that it shows "showing first 5,000". Narrow the JQL filter if you hit this.

Permissions and data

The app requests one read-only scope, read:jira-work. It cannot create, change or delete anything. It is built natively on Atlassian Forge and carries the Runs on Atlassian designation: it makes no outbound network requests and stores no data of any kind. See the privacy policy for details.
